## Public marketing site — scope check

This is an unauthenticated, public site with no customer data or auth tokens. Flag (don't just accept) any change that:
- Adds a server-side call to the ConvoMem API using a real API key/credential — this repo should not hold product credentials.
- Hand-edits `src/routeTree.gen.ts` — it's generated by `bun run generate-routes` and should never be edited directly; a PR that touches it by hand likely forgot to regenerate instead.
- Adds a new route or content section without a matching update to `scripts/generate-sitemap.ts` or `scripts/generate-llms.ts` — new pages that aren't in the sitemap/llms.txt are invisible to search and AI crawlers.

## Style

- Bun + Biome — don't suggest npm/yarn/pnpm commands or ESLint/Prettier config; `bun run check` is the single lint+format command.
- Content (blog/changelog/docs) is MDX under `src/content/` — prefer adding content there over hand-rolled React pages for prose.
