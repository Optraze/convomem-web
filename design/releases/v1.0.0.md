# Website v1.0.0

The marketing repository's first versioned release. Product, API and SDK versions are independent; their published content is preserved.

## Release baseline

- Repository: Optraze/convomem-web, branch main.
- Starting HEAD and origin/main: 7f07251fcd9e292d99d7125662cf6ac23a62126f.
- No earlier website tags or GitHub releases existed.
- The existing uncommitted marketing/docs redesign is included. The user's reference screenshot, unused component experiments, rejected image and unused old font remain local and unstaged.
- No server, SDK, database, or infrastructure repositories are changed.

## Included

- Light marketing design, original logo, Geist typography, forty source-verified capabilities, customer-support examples and responsive pricing.
- Compact layouts use category disclosures rather than wrapped category pills. All forty records remain server-rendered. Switching categories preserves the tapped row's position. Customer-history controls sit below the quote when the page stacks.
- Full 155-second original HTML film, muted initially, click-to-play/pause, seek, expand, and original mixed narration/dialogue/background music. One native media clock drives the animation. Byte ranges work on Vite and Node as well as static CDN hosting. Offscreen/background playback pauses and reduced motion prevents autoplay.
- Developer docs with compact navigation, search, code controls and persistent Light/Dark/System themes. Blog and changelog share the new resource design.
- Canonical URLs, distinct metadata/social images, structured data, sitemap and published-only Markdown exports. Archive collection schemas and crawl-reachability checks cover all public pages. Draft and unknown routes return real 404s.
