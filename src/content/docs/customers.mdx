Customers are the core identity entity in ConvoMem. All memories and conversations are
scoped to a customer.

## Lookup

Find a customer by email, phone, external ID, or customer ID. This is the most common
way to identify a customer at the start of a conversation. The response also carries a
prompt-ready `context` brief (see [AI agents](/docs/agents)).
Pass `autoCreate=true` to register a first-time customer.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers/lookup?email=alice@example.com"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="lookup.ts">
  ```typescript
  const result = await client.coldOpen({ email: 'alice@example.com' })

  if (result.found && result.customer) {
    console.log('Customer:', result.customer.id)
  }
  ```
  </CodeTab>
  <CodeTab language="python" filename="lookup.py">
  ```python
  from convomem import CustomerIdentity

  result = client.cold_open(CustomerIdentity(email="alice@example.com"))

  if result.found and result.customer:
      print(f"Customer: {result.customer.id}")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  use convomem::CustomerIdentity;

  let result = client.cold_open(
      &CustomerIdentity::from_email("alice@example.com"),
      None, // auto_create
      None, // user_name
      None, // max_tokens
  ).await?;

  if let Some(customer) = result.customer {
      println!("Customer: {}", customer.id);
  }
  ```
  </CodeTab>
</CodeTabs>

When no customer matches and `autoCreate` is off, the response is
`{ "found": false, "customer": null }`.

## Create

Create a new customer profile. Provide at least one of `email`, `phone`, or
`externalId`; each must be unique within your organization.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -X POST -H "X-API-Key: $CONVOMEM_API_KEY" \
    -H "Content-Type: application/json" \
    "https://api.convomem.com/api/v1/customers" \
    -d '{"name": "Alice", "email": "alice@example.com"}'
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="create.ts">
  ```typescript
  const customer = await client.createCustomer({
    name: 'Alice',
    email: 'alice@example.com',
  })

  console.log('Created:', customer.id)
  ```
  </CodeTab>
  <CodeTab language="python" filename="create.py">
  ```python
  customer = client.create_customer(name="Alice", email="alice@example.com")

  print(f"Created: {customer.id}")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  use convomem::CustomerCreateRequest;

  let customer = client.create_customer(
      &CustomerCreateRequest {
          name: Some("Alice".into()),
          email: Some("alice@example.com".into()),
          ..Default::default()
      }
  ).await?;

  println!("Created: {}", customer.id);
  ```
  </CodeTab>
</CodeTabs>

## List

List customers with pagination. Returns the people who have talked to **your key's
agent** — someone who only ever contacted a different agent won't appear here.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers?page=1&limit=20"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="list.ts">
  ```typescript
  const { customers, total } = await client.listCustomers({
    page: 1,
    limit: 20,
  })

  console.log(`Showing ${customers.length} of ${total} customers`)
  ```
  </CodeTab>
  <CodeTab language="python" filename="list.py">
  ```python
  result = client.list_customers(page=1, limit=20)

  print(f"Showing {len(result.customers)} of {result.total} customers")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  let result = client.list_customers(Some(1), Some(20), None).await?;

  println!("Showing {} of {} customers", result.customers.len(), result.total);
  ```
  </CodeTab>
</CodeTabs>

## Get

Retrieve a single customer by ID.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="get.ts">
  ```typescript
  const customer = await client.getCustomer({
    customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12',
  })
  console.log(customer.name, customer.email)
  ```
  </CodeTab>
  <CodeTab language="python" filename="get.py">
  ```python
  customer = client.get_customer(
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12")
  )
  print(customer.name, customer.email)
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  let customer = client.get_customer(
      &CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12")
  ).await?;
  println!("{:?} {:?}", customer.name, customer.email);
  ```
  </CodeTab>
</CodeTabs>

## Update

Update customer fields. Fields you omit are left unchanged.

<Callout type="warning" title="metadata is replaced, not merged">
Sending `metadata` replaces the stored metadata object as a whole. To change one key,
read the customer first and send the complete object with your change applied.
</Callout>

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -X PATCH -H "X-API-Key: $CONVOMEM_API_KEY" \
    -H "Content-Type: application/json" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12" \
    -d '{"name": "Alice Smith", "metadata": {"plan": "pro", "region": "eu"}}'
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="update.ts">
  ```typescript
  const updated = await client.updateCustomer(
    { customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12' },
    { name: 'Alice Smith', metadata: { plan: 'pro', region: 'eu' } },
  )
  ```
  </CodeTab>
  <CodeTab language="python" filename="update.py">
  ```python
  updated = client.update_customer(
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12"),
      name="Alice Smith",
      metadata={"plan": "pro", "region": "eu"},
  )
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  use convomem::CustomerUpdateRequest;

  let updated = client.update_customer(
      &CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12"),
      &CustomerUpdateRequest {
          name: Some("Alice Smith".into()),
          metadata: Some(serde_json::json!({ "plan": "pro", "region": "eu" })),
          ..Default::default()
      }
  ).await?;
  ```
  </CodeTab>
</CodeTabs>

## Delete

Request permanent erasure of a customer and their owned conversations and memories.
Check the HTTP response before treating the request as complete.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -X DELETE -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="delete.ts">
  ```typescript
  await client.deleteCustomer({ customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12' })
  ```
  </CodeTab>
  <CodeTab language="python" filename="delete.py">
  ```python
  client.delete_customer(
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12")
  )
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  client.delete_customer(
      &CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12")
  ).await?;
  ```
  </CodeTab>
</CodeTabs>

<Callout type="danger" title="Permanent deletion">
Successful erasure cannot be undone. If retained analytics, shared evidence, or an
unexpired export cannot be safely attributed, the API returns `409` and preserves
the customer's data for operator review (see the `ERASURE_*` codes in
[Errors & limits](/docs/errors)). Do not treat this conflict as success or retry it in
a tight loop. Previously downloaded files and copies held by your own integrations are
outside ConvoMem's deletion boundary.
</Callout>

Customer statistics and duplicate-profile review are dashboard workflows, not
public SDK operations. The integration contract focuses on identity resolution,
customer CRUD, conversation capture, recall, and handoff.

## Handoff

Generate a full cross-channel briefing — conversation journey, key memories, sentiment
trend, open-issue detection, and a narrative — for a human agent taking over.

See the dedicated [Handoff](/docs/handoff) page for the full reference.

## Response fields

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique customer identifier |
| `name` | string | Customer name |
| `email` | string | Email address |
| `phone` | string | Phone number |
| `externalId` | string | External system identifier |
| `metadata` | object | Custom metadata |
| `createdAt` | string | ISO-8601 creation timestamp |
| `updatedAt` | string | ISO-8601 last update timestamp |
