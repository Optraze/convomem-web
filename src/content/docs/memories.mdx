Memories are durable facts extracted from customer conversations. They persist across
sessions and are retrieved at the start of future interactions.

<Callout type="note" title="Extraction is asynchronous">
When you ingest a conversation, memory extraction happens in the background. Facts
become searchable within a few seconds. Build your flows around recall-then-capture,
not capture-then-immediately-recall.
</Callout>

## Ingest

Send conversation turns for a known customer to the extraction pipeline. The endpoint
returns `202` with a `captureId` you can poll at `GET /capture/:captureId`.

```bash title="Terminal"
curl -s -X POST -H "X-API-Key: $CONVOMEM_API_KEY" \
  -H "Content-Type: application/json" \
  "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12/memories/ingest" \
  -d '{
    "messages": [
      {"role": "user", "content": "I prefer email over phone"},
      {"role": "assistant", "content": "Noted, I have updated your preference."}
    ],
    "channel": "CHAT"
  }'
# → { "captureId": "0b6f4c1e-3d2a-4e8b-a7c9-5f1d2e3b4a6c", "status": "queued" }
```

<Callout type="tip" title="Using an SDK?">
The SDKs send turns through [`capture`](/docs/capture), which feeds the same extraction
pipeline and also resolves the customer and manages the conversation session.
</Callout>

## Lookup by topic

Retrieve the most relevant memories for a specific topic. ConvoMem ranks facts by
relevance and returns them with a pre-built context string.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12/memories/lookup?topic=billing"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="lookup.ts">
  ```typescript
  const { context, memories } = await client.lookup('billing', {
    customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12',
  })

  console.log('Context:', context)
  console.log('Memories:', memories.length)
  ```
  </CodeTab>
  <CodeTab language="python" filename="lookup.py">
  ```python
  from convomem import CustomerIdentity

  result = client.lookup(
      "billing",
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12"),
  )

  print(f"Context: {result.context}")
  print(f"Memories: {len(result.memories)}")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  use convomem::CustomerIdentity;

  let identity = CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12");
  let result = client.lookup("billing", &identity, None, None, None).await?;

  println!("Context: {}", result.context);
  println!("Memories: {}", result.memories.len());
  ```
  </CodeTab>
</CodeTabs>

## List

List all memories for a customer with pagination.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -H "X-API-Key: $CONVOMEM_API_KEY" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12/memories?page=1&limit=20"
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="list.ts">
  ```typescript
  const { memories, total } = await client.listMemories(
    { customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12' },
    { page: 1, limit: 20 },
  )

  for (const mem of memories) {
    console.log(`- ${mem.content} (${mem.category})`)
  }
  ```
  </CodeTab>
  <CodeTab language="python" filename="list.py">
  ```python
  result = client.list_memories(
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12"),
      page=1,
      limit=20,
  )

  for mem in result.memories:
      print(f"- {mem.content} ({mem.category})")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  let identity = CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12");
  let result = client.list_memories(&identity, Some(1), Some(20), None).await?;

  for mem in &result.memories {
      println!("- {:?} ({:?})", mem.content, mem.category);
  }
  ```
  </CodeTab>
</CodeTabs>

## Add manually

Add a memory directly without going through the extraction pipeline. Manual memories
are available for recall immediately. Any identity field works; when you omit
`category`, it defaults to `context`.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -X POST -H "X-API-Key: $CONVOMEM_API_KEY" \
    -H "Content-Type: application/json" \
    "https://api.convomem.com/api/v1/customers/memories" \
    -d '{"content": "Prefers dark mode", "category": "preference", "email": "alice@example.com"}'
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="add.ts">
  ```typescript
  const memory = await client.addMemory(
    'Prefers dark mode',
    { email: 'alice@example.com' },
    { category: 'preference' },
  )

  console.log('Memory ID:', memory.id)
  ```
  </CodeTab>
  <CodeTab language="python" filename="add.py">
  ```python
  memory = client.add_memory(
      "Prefers dark mode",
      CustomerIdentity(email="alice@example.com"),
      category="preference",
  )

  print(f"Memory ID: {memory.id}")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  let memory = client.add_memory(
      "Prefers dark mode",
      &CustomerIdentity::from_email("alice@example.com"),
      Some("preference"),
  ).await?;

  println!("Memory ID: {}", memory.id);
  ```
  </CodeTab>
</CodeTabs>

## Update

Update an existing memory's content or category. Requires the customer's `customerId`.

<CodeTabs>
  <CodeTab language="curl" filename="Terminal">
  ```bash
  curl -s -X PATCH -H "X-API-Key: $CONVOMEM_API_KEY" \
    -H "Content-Type: application/json" \
    "https://api.convomem.com/api/v1/customers/f3b39d1b-2522-4a00-98df-8cdde783ba12/memories/c2a7e4b1-9f3d-4a6e-8b5c-1d2e3f4a5b6c" \
    -d '{"content": "Prefers dark mode and large fonts", "category": "preference"}'
  ```
  </CodeTab>
  <CodeTab language="typescript" filename="update.ts">
  ```typescript
  const updated = await client.updateMemory(
    'c2a7e4b1-9f3d-4a6e-8b5c-1d2e3f4a5b6c',
    { content: 'Prefers dark mode and large fonts', category: 'preference' },
    { customerId: 'f3b39d1b-2522-4a00-98df-8cdde783ba12' },
  )

  console.log('Updated:', updated.content)
  ```
  </CodeTab>
  <CodeTab language="python" filename="update.py">
  ```python
  updated = client.update_memory(
      "c2a7e4b1-9f3d-4a6e-8b5c-1d2e3f4a5b6c",
      CustomerIdentity(customer_id="f3b39d1b-2522-4a00-98df-8cdde783ba12"),
      content="Prefers dark mode and large fonts",
      category="preference",
  )

  print(f"Updated: {updated.content}")
  ```
  </CodeTab>
  <CodeTab language="rust" filename="main.rs">
  ```rust
  let identity = CustomerIdentity::from_id("f3b39d1b-2522-4a00-98df-8cdde783ba12");
  let updated = client.update_memory(
      "c2a7e4b1-9f3d-4a6e-8b5c-1d2e3f4a5b6c",
      &identity,
      Some("Prefers dark mode and large fonts"),
      Some("preference"),
  ).await?;

  println!("Updated: {:?}", updated.content);
  ```
  </CodeTab>
</CodeTabs>

## Response fields

### Memory

| Field | Type | Description |
| --- | --- | --- |
| `id` | string | Unique memory identifier |
| `content` | string | The memory in natural language |
| `category` | string | Category (e.g., `preference`, `account`, `intent`) |
| `memoryType` | string | Type of memory (e.g., `fact`, `preference`, `commitment`) |
| `speaker` | string | `customer` or `agent` |
| `confidence` | number | 0–1 extraction confidence (list responses) |
| `relevance` | number | Per-query relevance score (lookup responses) |
| `expiresAt` | string \| null | ISO-8601 expiry, if the fact is time-bound (list responses) |
| `createdAt` | string | ISO-8601 creation timestamp |

### MemoryContext (lookup response)

| Field | Type | Description |
| --- | --- | --- |
| `context` | string | Pre-built context string for prompt injection |
| `tokenCount` | number | Approximate token count of the context |
| `memories` | Memory[] | Array of relevant memories |
