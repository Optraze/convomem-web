## Features

- **Multi-agent workspaces** — Split your account into separate workspaces per use case (support, sales, onboarding, etc.), each with its own capture prompt, PII filters, and retention window
- **Unified customer identity** — Customers stay recognized across every workspace in your account, even as conversations and insights are scoped per workspace
- **Per-workspace API keys** — Bind API keys to a single workspace so integrations only ever touch the data they should
- **Cross-workspace views** — Opt into an "all agents" view on Dashboard, Customers, and Insights when you need the combined picture

## Plan limits

- Starter: 2 workspaces
- Growth: 5 workspaces
- Pro: 15 workspaces
- Scale: 50 workspaces
- Custom: unlimited
